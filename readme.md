\# Cards Network Rules Assistant 💳 🤖



\### High-Precision RAG Engine for Transaction Processing Rules



This project implements a production-grade RAG pipeline designed to navigate dense technical documentation for global card networks. It solves the "needle in a haystack" problem for compliance officers and product managers.



\## 🚀 Product Impact

\* \*\*Reduced Research Latency:\*\* Cuts down rule-lookup time from \~20 minutes to <10 seconds.\[cite: 1]

\* \*\*Compliance-as-Code:\*\* Automates the retrieval of complex rules, reducing human error in high-stakes payment environments.\[cite: 1]



\## 🏗️ Technical Moat

\* \*\*Parent-Child Retrieval:\*\* Optimized for technical search. It uses 400-character "Child" chunks for granular similarity matching but provides the full "Parent" section context to the LLM for high-fidelity, grounded answers.

\* \*\*Technical Query Expansion:\*\* Automatically translates user questions into technical industry terminology (ISO 8583, DE elements) to bridge the gap between human language and technical documentation.\[cite: 2]

\* \*\*Reasoning Transparency:\*\* Features a custom UI "Reasoning Trace" that exposes the query transformation, similarity scores, and page citations to eliminate "black box" AI concerns.

\* \*\*Operational Awareness:\*\* Built-in token-cost tracking to monitor and optimize query ROI.\[cite: 1, 2]



\## 🛠️ Tech Stack

\* \*\*LLM:\*\* OpenAI GPT-4o-mini\[cite: 2]

\* \*\*Vector Store:\*\* FAISS\[cite: 2]

\* \*\*Frameworks:\*\* LangChain \& Streamlit\[cite: 1, 2]
